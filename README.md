# 智渝游——重庆文旅智能服务平台

智渝游是面向重庆区县及乡村自由行场景的 AI 文旅应用，围绕“行前规划、途中参考、景区预约、特产购买和游后分享”构建完整服务流程。

## 核心能力

- 基于用户出发地、目的地、天数、人数和偏好生成个性化路线
- 使用 RAG 旅游知识库降低大模型虚构景点和行程信息的风险
- SSE 流式输出 Markdown 行程，并自动解析每日路线节点
- 腾讯地图地点搜索、坐标定位和路线可视化
- 实时天气、空气质量、紫外线和穿衣建议
- 多轮 Function Calling 旅游 Agent
- 景区预约入口和当地农产品交互卡片
- 用户、购物车、订单、社区和会员数据管理

## Agent 工具

“渝小智”旅游 Agent 可根据用户意图自主调用：

- 景区预约入口查询
- 站内农产品检索
- 联网搜索
- 网页正文读取

工具结果会以 SSE 事件返回前端，并渲染为可操作的预约卡片或商品卡片。

## RAG 路线规划

项目将重庆区县与景区资料存储在 MySQL 中，使用轻量文本向量、余弦相似度、关键词匹配和地区规则加权完成混合检索。召回结果作为事实上下文注入 DeepSeek，再生成结构化的逐日旅行计划。

## 技术栈

- 前端：HTML、CSS、JavaScript
- 后端：Node.js、Express
- 数据库：MySQL
- AI：DeepSeek API、Function Calling、RAG、SSE
- 地图与实时信息：腾讯地图 API、大模型联网查询
- 安全：JWT、bcrypt、服务端密钥管理、SSRF 地址校验

## 本地运行

```bash
npm install
cp env.example .env
npm start
```

根据 `env.example` 配置数据库、模型接口和地图密钥。请勿提交真实 `.env`、API Key、数据库密码或运行时用户数据。
